Data safety

Your entries are protected in four ways, so nothing gets lost.

  • Trash: deleting an entry only hides it. Open Pass entries → Trash to restore it.
  • History: every edit keeps the earlier version of the entry in the database.
  • Automatic backups: a backup file is written to the backups folder after every change, and daily copies are kept for 30 days.
  • Restore never deletes: restoring a backup only adds or updates entries.

Inventory rules

How this tracker counts and allocates passes.

  • Pass quantity is reserved when an entry is saved, regardless of Sent or Pending status.
  • Available passes cannot go below zero.
  • Daily limits cannot be lowered below the quantity already allocated.
  • Every date follows the default daily limit unless you set a custom limit for that date on the dashboard.
  • Entry creation time is stored automatically; event date can be selected separately.
  • Deleting an entry (moving it to Trash) releases its passes back to that day; restoring it takes them again.
